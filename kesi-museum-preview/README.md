# 苏州缂丝工坊 · 一梭入画

这是基于你提供的 v24 游戏与 GLB 织机模型制作的独立演示副本。原始 ZIP、原始游戏和桌面上的 GLB 均未改动。

## 运行

项目内已包含模型和运行所需的查看器；运行时不依赖外网。安装 Python 3 后，在本目录启动静态服务器：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8000`。不要直接双击 `index.html`，因为浏览器通常会阻止本地模块加载。

## 演示流程

1. 拖动模型查看织机；点右侧部件名称看局部。
2. 点“织出第一梭”观看约 22 秒转场。按 Esc 可跳过。
3. 进入 v24 游戏副本；左上角可回到模型导览。

## 工艺准确性

织机模型的几何结构未改动。模型导览标注经面、脚踏、织面、拨子；按钮名称对应 GLB 中的组件组。转场约 22 秒：镜头环绕织机后推近经面与卷布花样；粉、赭金、青绿细丝从蓝布上的牡丹花瓣与叶片纹样显现，沿花样汇向花心，再向外展开并转化为游戏莲华。这是展品到纹样的视觉过渡，不表现纬线由机械自动产生。莲华成形与旋转时，镜头沿花样外缘缓慢绕弧并轻推近，随后回到织机原有视角，织物背景产生视差以增强空间感；莲华再沿丝线牵引向前跃起，带倾身完成一周旋转；随后莲瓣褪成白色丝线，镜头先拉回织机，再顺着白线推近经面，白线展开成经线，呼应游戏第一关“整经上机”，并与游戏中的白色经线交叉淡入。镜头环绕只用于展示视角，不让踏杆、综或梭子作未经核实的机械运动。莲华飞起与形态转换属于连接展品和游戏的视觉表达，不伪装成织机上的真实操作。其说明依据苏州非遗资料所述的“通经断纬”、脚踏分层经线、按纹样分段分区织纬等工艺特点；正式展陈前建议由传承人核对讲解词。

## 文件

- `index.html`：导览、交互模型、转场及游戏嵌入入口。
- `models/kesi_loom_peony.glb`：用户提供模型副本。
- `game/`：v24 游戏的完整独立副本，文件与来源包内 `dist/` 一致。
- `vendor/`：Three.js r170 及 GLTFLoader，用于本地离线展示 GLB。其许可证随包附上。
