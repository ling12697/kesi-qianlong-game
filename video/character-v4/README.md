# 指定男织工：人物第四轮初模与动作测试

人物依据用户指定角色设定，以及由该设定引导生成的正脸参考进行制作。不能将其称为对原人物的精确扫描或已确认还原。原始设定图片没有在本地逐像素使用。

这一轮改用连续的立体头颅：正脸几何来自参考正脸的面部关键点和推断深度，后脑、耳朵及颈部为建模推断；额发为独立三维发束。它不是随镜头转动的照片平面。当前头部仍没有眨眼和口型系统。

`artisan.glb` 与 `artisan-v4.blend` 是独立人物；`artisan-motion.glb` 带坐姿手臂、手指和头部的动画；`artisan-v4-motion-scene.blend` 包含原织机与真实相机轨迹；`seated-motion.mp4` 是 6 秒、24 fps 的静音动作测试。

此测试只检查人物坐姿、手臂伸收、手指放松与镜头缓慢移动。它没有完成真实的送梭、压纬及脚踏机械联动，更不是 A01–A09 短剧成片。脚保持在原踏板处，不将未经核实的踩踏循环当作真实织造。

`motion-checks.json` 记录 13 个姿势与凳面的网格交叉检查。这不等于检查了每一帧、所有衣物自交、手指与工具接触或全织机碰撞。`validation.json` 检查人物蒙皮结构及原织机 SHA-256。

原织机 GLB 文件未改变。人体、权重和骨骼来自 MakeHuman Community 官方 CC0 数据；面部点位提取使用 MediaPipe，几何深度属于估计。参考正脸、面部点位、构建脚本均保存在本工作区。

用户反馈 GitHub 与之前的本地视频链接无法打开；这里仅记录实际工作文件，不能将工作区保存等同于用户已经收到可播放附件。

本目录提供 GLB、MP4、实际渲染图和检查报告；可编辑 Blender 工程与构建过程仍保存在工作区。面部拓扑点位提取使用 MediaPipe，许可证见 MEDIAPIPE-LICENSE.txt。新视频已完整解码验证：H.264、640×480、24 fps、144 帧、6 秒、无音轨。画质属于低采样动作检查，真人质感、服装、发型、完整织造动作和 A01–A09 成片仍未完成。
