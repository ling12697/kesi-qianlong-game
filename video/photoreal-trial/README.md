# 五秒人物试镜：低头理线

状态：准备人物首帧、原织机渲染和视频生成指令。当前环境没有可调用的视频生成服务；本目录不会把静态图片或镜头缩放冒称为生成的人物视频。

唯一身份参考：用户最新提供的“缂丝织工角色设定”原图。此前的程序化人物、生成后再重建的头部、近似 GLB 角色均已被用户否定，不得作为本轮人物参考。

人物特征以原图为准：成年中国男性、短而自然蓬松的黑碎发、原有脸型和五官；米灰褐色提花盘扣上衣、卷至前臂的袖口、宽松黑裤与浅底黑布鞋。不得重新设计、改变年龄、加胡须或换脸。

本轮人物首帧是独立坐姿素材，不含重画的织机。试镜动作只用于检查人物身份、真人感和连续小动作，不等同于完整缂丝工艺演示。

原织机：直接读取用户 GLB 渲染，模型文件保持不变。正式合成时需分别提供人物、织机背景、人物前方机件遮挡、接触阴影和工具图层。手与梭子、拨子和经线的接触必须逐镜校正，不能仅靠长段文字保证无穿插。

视频生成时同时提交用户原角色设定图和经检查的首帧。平台若不支持人物参考，则不应仅凭文字重建此人。视频制作工具需由具备人物参考和动作参考能力的平台提供。

参数建议：16:9，5 秒，正常速度，固定种子（若平台支持），低幅度动作，参考强度优先保留身份；分辨率按平台原生能力选择。首轮关闭美颜和风格改写。

0.0–1.0秒：自然坐稳，肩膀放松，视线落在手中的丝线上。
1.0–3.0秒：左手轻扶丝线，右手拇指与食指夹住短段丝线，缓慢移动约2厘米；手腕和肘部随动。
3.0–4.0秒：右手停住并稍微放松手指，丝线仍由双手控制。
4.0–5.0秒：双手保持，轻微呼吸；保持同一张脸，不添加新动作。
镜头：五秒内缓慢前移约3%，视角不跨轴、不绕人旋转，保留手部与面部。

通过标准：首尾帧及中间帧均与原图是同一人物；皮肤与眼睛自然；手指数量、关节和动作连续；衣服不闪变；人物与坐具没有穿插。未通过则只返修该镜，不扩展到九个镜头。

脚本关系：该试镜服务于 A02/A03 的人物与理线动作准备。原脚本白马甲设定已由用户最新指定的提花盘扣上衣覆盖。正式短剧再把脚本交互任务改为叙事动作，不呈现点击按钮或游戏提示。
