# A08：拨紧纬线动作研究

本包是 8 秒、1280×720、24 fps 的男织工手部近景，带中文合成男声与字幕。它是依据用户两段操作参考制作的阶段小样，尚不是完整 A01–A09 短剧。

[播放或下载 MP4](./A08-comb-study.mp4) · [预览图](./A08-poster.png)

动作显示一手持双头木拨子，另一手稳定放在经面上的小梭；齿端落入原经线间隙，向织工方向短拨，提起并复位。局部新增蓝色纬线随接触向织口收紧，提起后保留位置。教学节奏经过放慢，固定近景便于观察工具接触。视频播放一次后结束，不作为连续织造循环使用。

用户提供的原缂丝机单独加载；66 个原网格的几何、材质与世界变换均与原始 GLB 比对一致，原文件 SHA-256 为 `23caa52aaa02af6f9a0bd81529e7498821263cc11b89b83ba6d16397a1b2e8bd`。拨子、小梭和局部纬线是独立演示物，未替换原机。

核验包含 192 帧手/前臂、工具与原机构件的网格交叉检查，手指骨段与弯曲范围检查，实际蒙皮表面到拨子两侧及支托小梭的间隙检查；并抽查原生骨骼与最终播放的骨骼、16 个皮肤点位置一致。各 JSON 提供实际结果。接触间隙使用模型作者单位，并非已标定的实物米制测量。几何检查不等于工艺专家审定，也未模拟皮肤受压或丝线力学。

人物使用男性骨架与手部。最终面部定妆尚未通过，此版镜头没有展示脸，不能据此认定与用户角色设定图完全一致。参考中脚部周期不足以明确判断；本版不演示踏综、完整过梭，也未完成全身坐姿与凳面的最终验证。后续仍需完成这些动作、角色外观和 A01–A09 镜头。

原始操作视频、参考截图及账号界面未包含在本包中。动作分析见[核对记录](./动作核对记录.md)。人体技术基底采用 MakeHuman CC0 资产，参考点位分析使用 MediaPipe；相关许可证随附。上述项目不为本小样的工艺正确性背书。
