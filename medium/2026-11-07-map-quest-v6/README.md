# 御前观织｜中级第一关 v6

这是一个独立的 HTML5 原型目录，不覆盖 v5。包含“书房 → 舆图 → 普宁寺建筑观察 → 资料归档 → 佛像画样展开 → 第二关入口占位”的连续流程。未实现第二关玩法，也未改动中级第二、三关原内容。

## 运行

解压后双击 `index.html` 即可离线运行；不依赖 CDN、外部字体、远程脚本或服务器。也可以用任意静态网页服务器托管整个目录。请在横屏 16:9 或接近比例的设备上体验；竖屏会提示旋转设备。

## 操作流程

1. 点击桌上的舆图卷轴。桌面卷轴两端移动、纸面展开，镜头推近至可操作的 SVG 示意地图。
2. 拖动地图平移；滚轮、双指或屏幕按钮缩放。点击“准噶尔”和“承德·普宁寺”标记，地图局部高亮。资料只显示一句摘要，详情可主动展开。
3. 看完两处后收卷返回书房。点击出现的寺庙资料，拖动/缩放普宁寺现存状态照片，观察大乘之阁和建筑群环境两个提示点。
4. 收起照片资料后，把两份记录拖入书案卷宗；也可先点选记录，再点卷宗。卷宗翻开、收纳并合拢。
5. 点击呈上的画样卷轴，再点击画面展开真实作品图像。点“进入第二关”后进入明确的入口占位说明。

刷新页面会恢复最近步骤。右下角“重新开始第一关”会清除本关的本地进度。

## 结构

- `index.html`：页面、场景道具和探索视图结构。
- `source/styles.css`：16:9场景、场景深度、道具动画、转场与横屏小屏布局。
- `source/main.js`：流程状态、事件、进度保存与刷新恢复。
- `source/room.js`：书房与地图/寺庙观察视图的镜头转场。
- `source/map.js`：通用地图/照片指针拖动、滚轮/双指缩放。
- `source/temple.js`：建筑观察目标及其短说明。
- `source/archive.js`：拖放与点选归档、收纳反馈。
- `source/transition.js`：佛像画样揭示和第二关占位。
- `source/history.js`：历史文本、事实/研究论证标识、来源 URL。
- `source/history-sources.md`：历史考证说明及素材来源清单。
- `assets/characters/`：用户授权的四张完整人物场景合成图，原文件未修改。
- `assets/temple/`：普宁寺现存状态摄影，供本关建筑观察。
- `assets/artwork/`：项目 v4 内嵌的简本、繁本图像，沿用原数据，不做裁切或修改。

## 人物素材限制

现有乾隆与太监素材都是人物和场景合成的完整图片，没有透明人物图层或独立手臂/手部姿势。因此 v6 不替换人物图、也不通过整图交叉淡入淡出假装人物走动；连续反馈由卷轴、文书、卷宗、镜头和局部高亮承担。若要实现可信的太监走近、呈递、指点、收卷和乾隆翻阅动作，需要用户确认过的透明分层人物素材（身体、手臂/手部姿势分别分层），或同画风、同服饰、同尺寸的动作母版；当前没有自行生成替代人物。

## 第二关状态

仓库中的现有 v4 是包含多个章节的整体页面，没有可直接链接进入的独立“佛像找不同”入口。为遵守不修改第二关的要求，v6 在佛像画样展开后提供一个真实占位，解释入口限制，并附现有中级完整页面链接；没有伪造第二关完成状态。
