# v6.3 第三关第一阶段测试记录

## 已通过的程序检查

- Node.js VM 语法解析通过：`level3/models/mesh-data.js`、`level3/viewer.js`、`level3/game.js`。
- 网格结构检查通过：194 个对象、7 个分组（台基 10、回廊 12、柱架 41、墙 17、屋顶 65、窗 34、抱厦 15）；面索引无越界、无少于 3 个顶点的面。
- 新目录里的 `mesh-data.js` JSON 与既有原脚本的网格 JSON 完全一致，未改变顶点或面数据。
- 代码静态核对：两个线索标记、相机平滑转向、内部滑块只控制 `wall` / `window` 两组透明度；三个背板落点均接受安置，不根据未记载的横向坐标判对错；二层北向位置反馈用“研究推定”表述。
- Mock Canvas 运行：用 Node 模拟 Canvas 2D 绘制 API 渲染 194 个对象，初始绘制、墙窗透明度 50%/100%、重置和两个屏幕锚点投影均无运行错误。这是代码级模拟，不是浏览器视觉测试。
- 第二关完成卡片的本地第三关入口和所有本地脚本、图片引用已核对。

## 尚未通过 / 未完成的验收项

- 本机本轮没有受允许的浏览器运行入口，未实际打开页面，因此没有完成鼠标旋转、触控旋转、缩放、线索点按、滑块、画样拖拽、吸附及音效的人工通关测试。
- 没有真实手机设备测试；不能声称鼠标或手机触控验收通过。
- 未提供在线部署，也没有实际页面运行截图。
- 找到的建筑模型不是 GLB/GLTF，而是既有 JS 网格模型。其几何与组结构已复核，但 GLB 加载流程本阶段无法测试。
- 尚未进入陈设物件系统开发；待第一阶段浏览器与触屏实测通过后再开始。
