# 历史文字与图片来源

## 历史依据

1. 王跃工、马晟楠：《乾隆朝〈缂丝无量寿尊佛〉轴考——以图像源流及功用为中心》，《故宫博物院院刊》2024年第9期。 [故宫博物院论文页面](https://www.dpm.org.cn/journal/365163.html)；[论文 PDF](https://www.dpm.org.cn/Uploads/File/2024/09/20/u66ecdf54ed53f.pdf)
   - PDF 页码 005：引述乾隆十九年（1754）十二月的缂丝佛像制作和修改画样记录，以及乾隆二十年（1755）正月画样获准记录。
   - PDF 页码 005：乾隆二十一年（1756）苏州送交缂丝佛像及原样的记录。
   - PDF 页码 010—011：作者论证繁本与承德普宁寺、北京清漪园须弥灵境营建及悬挂功用的关系。此为学术论证，不是档案原文，也不是游戏中的御前对白。
   - PDF 页码 010：论文引乾隆《普宁寺碑文》，说明寺院藏式部分仿照桑耶寺；并区分承德普宁寺“大乘之阁”和清漪园“香岩宗印之阁”。
2. 承德市文物局普宁寺景区资料：[普宁寺](https://wwj.chengde.gov.cn/art/2018/11/8/art_962_753948.html)。用于核对寺址及始建年代。页面若改版或失效，以上故宫论文仍是本关核心研究出处。

### 本关措辞原则

- 乾隆十九年（1754）画样制作、修改记录，乾隆二十年（1755）正月审样，以及乾隆二十年（1755）的军事事件分别叙述。游戏不写成“平定达瓦齐后才首次下令制作”。
- “繁本与普宁寺/须弥灵境悬挂使用关系”标为论文作者的研究论证。
- 清廷对蒙古、西藏藏传佛教的重视及其与边疆治理的联系，作为历史背景介绍；不把政治动机简化成玩家需要猜的选择题。
- 太监呈递、乾隆阅览、玩家归档均属游戏化情境演绎，不声称是真实会议、档案流程或圣旨原文。
