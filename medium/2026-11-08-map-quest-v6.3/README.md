# 苏州缂丝博物馆中级游戏 v6.3 · 第三关测试版

从 v6.2 另存出的独立副本，新增第三关第一阶段“探阁寻迹 → 查看内部 → 佛像安置”。v6.2、v6.1 与原第三关未覆盖或修改。v6.3 的第二关完成卡片新增通往 `level3/index.html` 的入口，第二关找不同和拼图逻辑不变。

## 运行

解压后打开 `index.html` 从第一关开始；也可以直接打开 `level3/index.html` 测第三关。无需 CDN、远程模型或外部运行库。

## 第三关第一阶段实现

- 复用此前项目中的大乘阁原始 JavaScript 网格数据，包含 194 个网格对象、7 个结构组（台基、回廊、柱架、墙、屋顶、窗、抱厦）。网格顶点和面数据原样提取，未重新生成建筑几何。
- 拖动旋转、滚轮或双指缩放；两个观察标记随视角显现。点标记后镜头平滑转向，并点亮完成记录。
- 两处线索全部发现后解锁内部观察滑块。滑块让原有墙、窗网格淡出，显露模型里现有柱架和回廊；没有拆分或平移建筑构件。
- 使用第二关繁本真实原图进行拖放安置，支持尺寸、高度调整、三个同属北向背板区域的落点、吸附反馈与轻微成功音效。三个横向落点是游戏交互示意，不设置唯一历史正确点。
- 安置结果明确标作研究示意。完成页陈述档案事实与学术推定，并将大乘阁木雕千手千眼观音与缂丝画作区分。
- 未实现殿内陈设物件系统；按开发顺序留待下一阶段。

## 必须知道的模型格式差异

仓库、v6.2、给定的“第二单元”素材目录以及可搜索的 Codex/Desktop 文件中，没有找到大乘阁 GLB/GLTF。找到的是 `2026-11-05/.../大乘阁模型原脚本.js` 中的既有 JS 网格数据和 Canvas 投影绘制器。此版沿用这份几何数据，并在新页面中复用网格进行交互；它**不是 GLB**，也不声称完成 GLB 加载。当前能检查的网格分组支持墙窗淡出和内部构件显露，因此使用真实网格组来观察，没有依赖剖面图替代模型分层。模型本身已有研究原型说明，不能当作实测复原。

若交付要求必须采用 GLB 文件，请提供此前确认的大乘阁 `.glb`；当前目录里仅找到缂丝织机 GLB，未拿它代替建筑模型。

## 历史边界

故宫博物院院刊 2024 年论文引用嘉庆二十四年《普宁寺佛像供器陈设等项清档》：“二层楼面北……面北挂画像佛一轴”。论文进一步推测，该轴可能是悬挂在观音像背后、朝北向回廊的《缂丝无量寿尊佛》繁本。游戏将“二层、面北”作为档案信息，将其与缂丝轴对应关系标为研究推定；A/B/C 只表示同一背板上的交互位置，不代表档案记录了具体横向坐标，也不会给出唯一正确答案。

来源：[故宫博物院论文页面](https://www.dpm.org.cn/journal/365163.html)。文章提及普宁寺大乘阁二层层高 8.45 米，并对“面北挂画像佛”与缂丝画的对应关系作推测。其他屏幕文案和场景均标为研究或游戏示意。
