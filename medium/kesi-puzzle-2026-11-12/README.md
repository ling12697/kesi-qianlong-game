# 缂丝文物拼图

独立的佛像拼图小游戏，仅含拼图环节和运行所需的繁本原图；不含三图观察、找不同或其他关卡。原图按比例切分为矩形拼图区域，游戏不修改文物画面。

## 打开方式

在本目录启动静态网页服务：

```sh
ruby -run -e httpd . -p 8794
```

浏览器打开 `http://127.0.0.1:8794/`。也可直接用支持本地资源的浏览器打开 `index.html`。

## 玩法

- 简单 2×3、普通 3×4、挑战 4×5。
- 点击两块进行交换，或拖动一块到另一块上交换。
- 实时显示归位数量；完成后显露完整原图。
- 支持重新打乱、重玩和切换难度。
