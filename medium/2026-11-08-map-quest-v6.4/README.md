# 苏州缂丝博物馆中级游戏 v6.4

v6.4 是从 v6.3 复制出的独立版本，只针对三个交互问题做局部修复。v6.3 文件夹和线上路径均保留不动；没有重做关卡、替换人物或佛像图像，也没有修改建筑网格数据。

## 运行

解压后打开 `index.html`，从第一关进入；也可以直接打开 `level2/index.html` 或 `level3/index.html`。页面脚本、图片与网格数据均放在本目录，不依赖 CDN 或远程模型。

## 本次修改

- **第一关书案：**舆图、寺庙资料、卷宗、两份调查记录和佛像画样按剧情阶段显示；隐藏物件明确关闭点击命中。归档阶段把两份记录与中央卷宗排开，完成归档后收起卷宗，再呈上画样。启动卷轴后立即禁用重复点击。
- **第二关拼图：**交换后同步更新每格的繁本原图裁切位置；首次点击选中并抬起图块，第二次点击交换；拖动图块跟手，目标格高亮，松开后交换或返回。每次交换伴随短暂视觉反馈，正确块数按实际图片位置计算，完成判定依赖全排列归位。支持 6、12、20 块三档及重新随机打乱。
- **第三关探阁：**开场先说明调查目标与佛像陈设研究推定的关系；分两步观察层叠屋檐、内部柱架与回廊。金色标记在接近目标角度时逐渐出现，点击后镜头平滑聚焦并显示建筑信息及其与后续陈设观察的关系；两处完成后再解锁内部观察。

## 史料与模型边界

第三关继续使用项目既有 JavaScript 网格研究模型，不是 GLB/GLTF，也不是实测复原；v6.4 没有改动其几何数据。对佛像可能悬挂位置的说明仍标为研究者推定，不认定横向具体位置。室内画样安置属于研究示意；不代表真实空间复原。历史来源见 `source/history-sources.md` 及第三关页面。
